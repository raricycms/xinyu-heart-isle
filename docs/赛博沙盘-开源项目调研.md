# 开源「赛博沙盘」项目调研

> 检索时间：2026-10。链接来自公开检索结果，License / 活跃度 / 部署方式请以仓库最新状态为准。
> 说明：本次环境无法直连 github.com 抓取页面，下方仓库链接来自搜索结果，建议逐一点开确认。

## 0. 先对齐概念

「赛博沙盘」不是标准技术名词，国内语境一般指：**在虚拟/仿真环境里复现网络空间（拓扑、资产、漏洞、攻击链），用于教学、演练、红蓝对抗和推演的"可交互沙盘"**。

对应到英文开源生态，其实横跨三个圈子：

| 中文说法 | 英文关键词 | 典型项目 |
| --- | --- | --- |
| 网络靶场 / 攻防演练环境 | cyber range | KYPO CRP、RANGE42、CyRIS、SecGen |
| 攻防推演 / 红蓝对抗 | adversary emulation、red team simulation | CALDERA、Atomic Red Team、BloodHound |
| 网络仿真沙盘 / 数字孪生 | network emulation、cyber simulation、RL gym | containerlab、Kathará、CyberBattleSim、CybORG |

所以答案不是"某一个项目"，而是"一条技术栈"：**仿真底座 + 场景生成 + 演练编排 + 攻击模拟 + 可视化**。

## 1. 完整/准完整「靶场平台」（最接近开箱即用的赛博沙盘）

| 项目 | 来源 | 特点 |
| --- | --- | --- |
| **KYPO Cyber Range Platform** | 捷克马萨里克大学 | 最完整的一档：OpenStack/K8s 编排 + Web 前端 + 训练与沙箱管理，有正式文档，欧洲多国在用。入口：[github.com/kypo-crp](https://github.com/kypo-crp)、[docs.platform.cyberrange.cz](https://docs.platform.cyberrange.cz/) |
| **RANGE42** | 卢森堡大学 | Kubernetes 原生靶场，声明式定义拓扑与场景，2025 年 Hack.lu 有专场分享。入口：[github.com/range42](https://github.com/range42)、[项目页](https://code.lhc.lu/projects/range42/) |
| **CyRIS** | 京都大学 | Python 编写，按描述文件在 KVM 上批量实例化靶场主机与网络，研究/教学经典。[github.com/cyb3rlab/cyris](https://github.com/cyb3rlab/cyris) |
| **CONCORDIA Cyber Range** | 欧盟 CONCORDIA 项目 | 2020 年开源的组件化靶场平台，[欧盟委员会发布页](https://digital-strategy.ec.europa.eu/en/node/9649) |
| **Tectonic** | 乌拉圭共和国大学 | 学术向靶场，PyPI 有 `tectonic-cyberrange` 包。[项目页](https://www.fing.edu.uy/inco/grupos/gsi/en/project/tectonic/)、[PyPI](https://pypi.org/pypi/tectonic-cyberrange/json) |
| **SecGen** | 社区 | 随机生成"带漏洞的靶机/场景"，非常适合给沙盘批量造靶子。[github.com/cliffe/SecGen](https://github.com/cliffe/SecGen) |
| **灵境 LingJing** | 国内 | 桌面级本地靶场，Windows/macOS（含 M 系列芯片跑 amd64 靶机），上手成本低。[github.com/414aaj/LingJing](https://github.com/414aaj/LingJing) |
| **CRaaS** | 学术（智能电网） | 云化智能电网靶场，偏研究原型，可借鉴架构 |

> 选型提示：KYPO / RANGE42 是"平台"，CyRIS / Tectonic 是"论文级系统"，SecGen 是"场景生成器"，灵境是"个人桌面靶场"，定位差异很大。

## 2. 仿真底座（自己搭沙盘的"地基"，最实用的一层）

- **containerlab** —— 声明式 YAML 定义容器化网络拓扑，秒级起停，现代红蓝/网络沙盘首选。[github.com/srl-labs/containerlab](https://github.com/srl-labs/containerlab)
- **Kathará** —— 轻量容器网络仿真，教学友好，已进入 Debian 打包流程。[github.com/KatharaFramework/Kathara](https://github.com/KatharaFramework/Kathara)
- **GNS3** —— 图形化老牌仿真，可挂真实设备镜像，适合网络+安全混合拓扑。
- **Mininet** —— SDN/OpenFlow 经典，轻量、脚本化强。
- **CORE / IMUNES / Cloonix / VNX** —— 更老牌的网络仿真器，仍有维护，适合特定场景。
- **Proxmox VE + Terraform + Ansible** —— 需要完整虚机（Windows 域、工控、真实漏洞环境）时的常见组合，KYPO 也是这个思路。

## 3. 演练/竞赛平台（沙盘上的"对抗组织层"）

- **CTFd** —— 最主流的开源 CTF/演练平台，插件生态大。[github.com/CTFd/CTFd](https://github.com/CTFd/CTFd)
- **GZCTF** —— 国内活跃，动态积分、容器靶机编排，适合 AWD/攻防演练。[github.com/GZTimeWalker/GZCTF](https://github.com/GZTimeWalker/GZCTF)
- **rCTF**、**FBCTF**（已归档）、**CTFd-Whale**（CTFd 容器靶机插件）—— 备选/补充。
- **Vulhub** —— 漏洞复现环境集合（docker-compose），沙盘里"靶子"的主要来源。
- **Vulfocus** —— 漏洞靶场平台，可一键启停、统一管理镜像。[github.com/fofapro/vulfocus](https://github.com/fofapro/vulfocus)
- **Metasploitable3 / OWASP Juice Shop / DVWA / WebGoat** —— 经典教学靶机。

---

## 4. 攻击模拟 / 红蓝对抗（推演里的"红军蓝军"）

- **MITRE CALDERA** —— 自动化攻击模拟与对抗演练框架，已移交 Apache 基金会（Apache Caldera 孵化中）。[github.com/mitre/caldera](https://github.com/mitre/caldera)
- **Atomic Red Team** —— ATT&CK 原子测试库，验证检测能力。[github.com/redcanaryco/atomic-red-team](https://github.com/redcanaryco/atomic-red-team)
- **Infection Monkey** —— 自动化攻击 + 防御有效性验证。[github.com/guardicore/monkey](https://github.com/guardicore/monkey)
- **BloodHound** —— AD 攻击路径分析，常作为"沙盘推演"素材。[github.com/SpecterOps/BloodHound](https://github.com/SpecterOps/BloodHound)
- **ATT&CK Navigator** —— 技战术覆盖度可视化，推演复盘很好用。
- 国内向：**Viper**（攻击面管理 + 红队模拟）、**AT&D 红客攻防系统**（靶场演练 + 检测 + 溯源，AI/大数据方向），可作参考。

## 5. 仿真 / 强化学习「沙盘」（研究向：AI 推演、策略博弈）

- **CyberBattleSim**（微软）—— 抽象企业网络的攻防模拟，RL 智能体训练经典。[github.com/microsoft/CyberBattleSim](https://github.com/microsoft/CyberBattleSim)
- **CybORG**（CAGE Challenge）—— 自主网络防御基准环境。[github.com/cage-challenge/CybORG](https://github.com/cage-challenge/CybORG)
- **Yawning Titan**（英国 DSTL）—— 抽象网络攻击模拟器，策略研究向。[文档](https://dstl.github.io/YAWNING-TITAN/)
- **NASim / NASimEmu** —— 网络攻击模拟 + 仿真，PyPI 有 `nasimemu`。
- **CSLE**（KTH）—— 自动化安全策略研究平台（控制论/博弈/RL）。[github.com/Limmen/csle](https://github.com/Limmen/csle)
- **CyberGym**（UC Berkeley，2025）—— 真实漏洞上大规模评测 AI 智能体的赛博 benchmark。
- 资源列表：[awesome-rl-for-cybersecurity](https://github.com/Kim-Hammar/awesome-rl-for-cybersecurity)

## 6. 可视化 / 态势大屏（沙盘的"界面"）

- **OpenCTI** —— 威胁情报知识图谱，天然适合做"沙盘关系图"。[github.com/OpenCTI-Platform/opencti](https://github.com/OpenCTI-Platform/opencti)
- **MISP** —— 情报共享与关联。
- **ATT&CK Navigator** —— 技战术矩阵。
- 前端：Cytoscape.js / AntV G6 / three.js / deck.gl —— 3D 赛博沙盘大屏基本靠这几个自研。
- 资产测绘底图：Amass、Nuclei、SpiderFoot、theHarvester 等（开源测绘/资产发现）。

## 7. 按场景的选型建议

| 目标 | 推荐组合 |
| --- | --- |
| 教学 / CTF / 入门演练 | CTFd 或 GZCTF + Vulhub/Vulfocus + Metasploitable3 |
| 企业红蓝对抗演练 | containerlab（或 Kathará）+ CALDERA + Atomic Red Team + OpenCTI 大屏 |
| 完整靶场平台（多人、多课程、可编排） | KYPO CRP 或 RANGE42 二次开发 |
| 批量造靶子 / 场景自动化 | SecGen + Vulhub + Ansible/Terraform |
| AI 推演 / 策略研究 | CyberBattleSim、CybORG、Yawning Titan、CSLE |
| 个人/单机快速体验 | 灵境 LingJing；或 Vulhub + docker-compose |

**最小可用赛博沙盘（MVP）参考架构**

```
拓扑与节点   containerlab / Kathará / Proxmox
场景与靶标   Vulhub + SecGen 生成的镜像
演练组织     CTFd / GZCTF（赛制、计分、容器下发）
攻击模拟     CALDERA + Atomic Red Team
观测与复盘   OpenCTI / ATT&CK Navigator + 自研大屏
隔离与回收   VLAN/VXLAN 或 K8s NetworkPolicy，快照回收
```

## 8. 落地注意事项

1. **License**：GPL/AGPL 项目（如部分网络仿真器）用于商业交付要注意传染性；MIT/Apache/BSD 更友好，一切以仓库 LICENSE 为准。
2. **活跃度**：不少"论文靶场"（CyRIS、Tectonic、CRaaS）停更多年，二次开发成本高；优先选近 12 个月有提交的。
3. **硬件**：完整虚拟化靶场吃 CPU/内存/存储，容器化方案（containerlab）资源占用低一个量级。
4. **国内合规**：等保、数据不出境、演练授权（务必有书面授权再对真实资产做任何测试）。
5. **工作量分布**：靶场平台里"网络隔离 + 镜像/快照管理 + 场景编排"占 70% 工作量，前端大屏反而是小头。
